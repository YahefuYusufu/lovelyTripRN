

My Travel App
Overview
My Travel App is a comprehensive travel management application available in multiple platforms. Currently, it is implemented using React Native and Expo, with additional versions developed in SwiftUI for iOS and Jetpack Compose for Android. The app helps users discover, add, and manage their favorite travel places with ease.

Features
View Places: Browse through a list of saved places with images and addresses.
Add Places: Easily add new places with a title, image, and location.
Map Integration: View places on a map and get a preview of their locations.
Location Picker: Use your device’s location or pick a location on the map to save new places.
Image Capture: Capture and upload images directly from the app.
Technologies Used
React Native & Expo: For cross-platform mobile development.
SwiftUI: For the iOS version of the app.
Kotlin & Jetpack Compose: For the Android version of the app.
React Navigation: For navigation within the React Native app.
Expo Image Picker: For accessing the device’s camera and photo gallery.
Expo Location: For location services and permissions.
Babel: For transforming modern JavaScript.
